One-shot locked check of the baseline-resistance screen (written 2026-10-24, before any locked
resistance value was read in this analysis).

Context: the 15 locked sensors were scored once for the frozen image model on 2026-10-23
(final_test_log.csv). This is a separate, later test of a different predictor (baseline
resistance in air), decided after that score and after the development screen analysis
(screen.json). It will be reported as such.

Predictor: log10 r_air_median from data/derived/r_air.csv (300 C, after stabilisation,
before the first acetone pulse). Non-responder: rel_resp_median < 0.01 (labels_v2.csv).
Sensors: those listed in locked_test_sensors.txt that have a label.

Primary: fixed threshold 10 kOhm (chosen as a round value from the development analysis);
flag a sensor if r_air_median < 10,000 ohm. Report sensitivity, specificity, balanced accuracy,
counts.
Secondary: AUC (low resistance = non-responder), 2,000-resample bootstrap 95% interval over
sensors, one-sided permutation p (10,000 label shuffles, AUC >= observed).
Criterion for "confirmed": AUC permutation p < 0.05 and balanced accuracy >= 0.70 at 10 kOhm.
Run once with screen_locked.py; the script refuses to run again if the log exists.
